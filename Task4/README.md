# Задание 4 — TCO для 100 магазинов

Тип модели — сценарный investment case; валюта — рубли в постоянных ценах, период — 36 месяцев, 100 существующих магазинов по две кассы. Это учебный расчёт с открытыми допущениями. Доступного `company-finance-kb` и финансовых данных VitaStore нет; внутренние ставки, лицензии и цены требуют подтверждения. Ни одно значение не выдаётся за коммерческое предложение поставщика.

| Файл | Роль |
|---|---|
| [assumptions.csv](assumptions.csv) | Изменяемые inputs с единицами, источником и описанием |
| [calculate_tco.py](calculate_tco.py) | Единственный расчётный движок, Python standard library / Decimal |
| [monthly-cashflow.csv](monthly-cashflow.csv) | 36 месяцев, количество магазинов, затраты и накопленный эффект |
| [tco.csv](tco.csv) | Итоговая таблица категорий: годы 1–3 для AS-IS и TO-BE |
| [sensitivity.csv](sensitivity.csv) | Изменение SaaS, ФОТ, обновления серверов, PaaS и терминалов |
| [checks.csv](checks.csv) | Проверки согласованности периодов, сумм и rollout |
| [metrics.json](metrics.json) | Точные результаты модели для повторного использования |
| [conclusion.md](conclusion.md) | Методика, ROI, срок окупаемости и границы достижения 40% |

Пересчёт: `python3 VitaStore/Task4/calculate_tco.py` из корня проекта. CSV имеет UTF-8 BOM, запятую как разделитель и точку в десятичной части; при импорте в Excel явно выберите эти параметры. CSV хранит результаты, формулы и зависимости воспроизводятся скриптом, поэтому редактировать итоговый TCO вручную не следует. Модель проверяет только заданный rollout 100 магазинов / 36 месяцев / один месяц overlap; для другого масштаба нужно изменить график, а не только одно поле inputs.

Включены будущие замены серверов, новые планшеты и резерв, лицензии POS/HAL/MDM, поддержка и выезды, сеть/LTE, ремонт и серверное питание, PaaS/backup/monitoring, inference, интеграция/обучение/миграция и резерв рисков. Периферия, эквайринг, ОФД, SAP и эксплуатация уже существующего Smart Fulfillment считаются одинаковыми в обоих сценариях и исключены из сравнения. Дополнительная миграция HQ-продуктов не включена: её экономику нужно считать отдельным кейсом, это не «бесплатный» результат данного TCO.

Не включены налоги/НДС, амортизация, финансирование, инфляция, дисконтирование, рост выручки, потенциальное снижение потерь продаж и денежный эффект ускорения M&A. Это cash TCO, а не P&L/NPV; остаточная стоимость оборудования и выручка от продажи legacy консервативно нулевые. Уже купленные серверы — sunk cost, но **будущая** плановая замена учитывается, если подтверждена. При появлении разных налоговых режимов/FX и невозмещаемого НДС расчёт необходимо уточнить.
